# MangoFilter

Comparador de productos y servicios entre tiendas online: costo total (precio + envío a tu ciudad) y tiempo de entrega en un solo lugar.

```bash
npm install
npm start      # Expo Go / emulador
npm test       # pruebas
```

- [documentacion.md](documentacion.md): funcionalidades, cómo ejecutar, decisiones y registro de cambios.
- [arquitectura.md](arquitectura.md): capas, estado, navegación, algoritmo de matching y accesibilidad.
- [propuesta_t_cnica_mangofilter.md](propuesta_t_cnica_mangofilter.md): propuesta técnica original.
